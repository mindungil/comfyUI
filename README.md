# ComfyUI (전북특별자치도 캡스톤 프로젝트 커스터마이징 버전)

본 저장소는 원본 ComfyUI(https://github.com/comfyanonymous/ComfyUI)를 기반으로  
전북특별자치도 캡스톤 프로젝트에서 활용하기 위해 커스터마이징한 버전입니다.  
인증(auth) 강화, GPU 환경(Rocm/CUDA) 지원 확대, 기능 확장, 운영 환경 최적화 등을 진행했습니다.  
민감한 정보는 포함하지 않았으며, 공개 가능한 범위 내에서 수정 내용을 기술합니다.

---

## 주요 커스터마이징 내용

### 1. 인증(Auth) 강화
- 사용자 접근 제어 구조 개선
- 인증 절차 보완 및 내부 운영 정책 반영
- 서비스 실사용 환경 기준의 보안 설정 강화

---

### 2. GPU 환경 확장 지원 (Rocm / CUDA)
- AMD GPU 환경을 위한 Rocm 6.x~7.x 기반 최적화 구성
- NVIDIA GPU 환경을 위한 CUDA 12.x 기반 설정 정비
- Rocm·CUDA 양쪽에서 모델 실행 파이프라인이 일관되게 동작하도록 개선
- 실행 스크립트 및 빌드 환경의 GPU 백엔드 호환성 점검 및 보완

---

### 3. 기능 및 워크플로우 확장
- 프로젝트 요구사항에 맞춘 커스텀 노드 추가
- UI 개선 및 내부 워크플로우에 적합한 처리 로직 보완
- 모델/에셋 디렉토리 구조 재정비
- YAML 기반 설정 파일을 통한 모델 검색 및 경로 관리 기능 강화

---

### 4. 운영 환경 최적화
- 서버 실행 옵션 및 초기화 프로세스 정비
- GPU/CPU 환경 변화에 따른 성능 향상
- 배포 및 업데이트 일부 자동화

---

### 5. 보안 및 안정성 개선
- 외부 의존성 정리 및 최신 버전 업데이트
- 예외 처리, 로깅 구조 개선
- 운영 환경 기준의 보안 규칙 반영
